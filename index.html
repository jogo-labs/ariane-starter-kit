Char Counter <ar-charcounter>

Par défaut

Compteur lié à un champ texte via `for`. Affiche le nombre de caractères restants. Passe en état `warning` quand il reste ≤ 20 % de la limite (seuil par défaut), puis en état `error` quand la limite est dépassée.

Seuil d'avertissement personnalisé

`warn-threshold="15"` déclenche l'état `warning` quand il reste ≤ 15 caractères. La zone de texte est pré-remplie pour illustrer l'état d'avertissement (45 caractères sur 60).

Icônes dans les slots

Les slots `warning-icon` et `error-icon` permettent d'ajouter un signal non-couleur conforme WCAG 1.4.1. Le contenu du slot est rendu à côté du compteur dans l'état correspondant.

⚠️ ❌

Label personnalisé

La prop `label` accepte la syntaxe `"singulier|pluriel"` — le composant choisit automatiquement la forme selon le nombre de caractères restants. Le même label est utilisé dans les annonces `aria-live` : l'annonce de passage en avertissement dit par exemple _"1 caractère restant"_ ou _"12 caractères restants"_. Sans pipe, le label est utilisé tel quel (compatibilité descendante).

Dropdown <ar-dropdown>

Mode menu

Avec des ar-dropdown-item, le panel reçoit automatiquement role="menu" et la navigation clavier est activée (↑↓ Home End Escape Tab).

Séparateur

Un `<hr>` placé entre des `ar-dropdown-item` reçoit automatiquement `role="separator"`. Stylez-le avec votre propre CSS — ici via une variable CSS du token de bordure.

Contenu libre

Sans ar-dropdown-item, le panel est un conteneur libre — aucun role ni navigation clavier n'est ajouté.

Contenu libre — formulaire, liste, texte…

Placement top-end

Le panel s'ouvre au-dessus du trigger, aligné à droite.

Distance personnalisée

Espacement en pixels entre le trigger et le panel (axe principal), piloté par la custom property CSS `--ar-dropdown-distance` (défaut : `var(--ar-anchor-distance)`, 4px).

Offset latéral

Décalage latéral en pixels du panel par rapport au trigger (axe transversal), piloté par la custom property CSS `--ar-dropdown-offset` (défaut : `var(--ar-anchor-offset)`, 0).

Trigger externe

L'attribut `for` accepte l'ID d'un élément déclencheur situé en dehors du composant. Utile pour les boutons dans une barre d'outils ou une autre zone de la page.

Désactivé

Combine `disabled` sur `ar-dropdown` et `aria-disabled="true"` sur le trigger — voir la section Accessibilité pour le détail. WCAG exempte les composants désactivés des exigences de contraste : `opacity: .5` est donc conforme.

Droits insuffisants pour effectuer cette action.

Tooltip <ar-tooltip>

Par défaut

Passez l'ID du trigger via `for`. La bulle s'affiche après `show-delay` ms (300 par défaut) et se masque après `hide-delay` ms (150 par défaut).

Texte d'aide contextuelle

Placement

Toutes les valeurs Floating UI sont supportées — `top`, `bottom`, `left`, `right` et leurs variantes `-start`/`-end`. Le composant bascule automatiquement si l'espace est insuffisant.

Placement top Placement bottom Placement left Placement right

Sans caret

Ajoutez `without-arrow` pour supprimer le caret directionnel — utile quand le tooltip est suffisamment proche du trigger ou dans un contexte visuel dense.

Tooltip sans caret

Sur une abréviation

Cas d'usage classique — `<abbr>` n'est pas interactif nativement, donc `tabindex="0"` est nécessaire pour que le tooltip soit accessible au clavier.

Le composant suit WCAG 1.4.13 pour garantir la persistance au survol.

Web Content Accessibility Guidelines — critère 1.4.13 : Content on Hover or Focus

Bouton icône

Complète un bouton sans libellé textuel — le tooltip joue le rôle de description visible. Attention, il ne remplace pas un `aria-label` sur le bouton lui-même.

Paramètres du compte

Délais personnalisés

`show-delay` et `hide-delay` contrôlent les temporisations en ms. Valeurs par défaut : 300 ms / 150 ms (conformes WCAG 1.4.13). Ici `show-delay="0"` pour une réponse immédiate.

Apparaît sans délai

Désactivé

L'attribut `disabled` bloque tout déclenchement sans modifier le DOM du trigger. Utile pour désactiver dynamiquement le tooltip selon le contexte.
